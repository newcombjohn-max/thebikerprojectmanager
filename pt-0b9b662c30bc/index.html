Part 1: the XML files (tests 1 to 5)

Do this for each test

  1. Project: File > Open > Browse, set the file type box to XML Format, pick the file, Open.
  2. Choose As a new project, then OK.
  3. If the Planning Wizard pops up: write down the task number it names, choose Continue, OK.
  4. Compare the dates with the card's table. If something differs, jot it down. That's all.
  5. Project: File > Save As > Browse, set Save as type to XML Format, name it as the card says (it ends in back.xml), Save. Close that project.

Part 2: the CSV files (tests 6 to 8)

The same plans as tests 1, 3 and 4, sent as CSV, to see whether Project handles CSV better than XML.

Do this for each test

  1. Project: File > Open > Browse, set the file type box to CSV (Comma delimited), pick the file, Open. The Import Wizard starts.
  2. Next, then New map, Next, then As a new project, Next.
  3. Tick Tasks. Leave Import includes headers ticked. Next.
  4. The mapping table: each column on the left (Name, Outline Level, Duration, Start, Predecessors, Resource Names) should already have the same name on the right. If any says (not mapped), click it and pick the field with the same name. Jot down whether you had to.
  5. Next, then Finish. Don't save the map.
  6. Planning Wizard, the date check and the save back are the same as Part 1, steps 3 to 5. The save-back is still XML Format.
